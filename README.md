# Error-counter
Per installare questo programma basta su "contaerrori.exe" dalla lista dei file.
Si apre una scheda, abbstanza in alto, a destra del nome del file c'è piccolina un'icona del download. Premendola si può scaricare il programma
In alternativa dal tasto verde con scritto "code" si può andare su "download zip" e dezzippando il file si trova anche contaerrori.exe
Aprendo il file .exe si può sfruttare il software.
